# Consent Route Studio

Design proposal for a privacy-conscious agent network that helps people explore community resource referrals while making data-sharing permissions visible and revocable.

## Competition and scope
Independent project concept for the [Open Agentic Web Challenge](https://cognizant-agenticweb.devpost.com/rules). The entrant must own and contribute original work. This repository contains planning material only until the entrant confirms the design and reviews the official specification and AI-use expectations.

## Architecture proposal
- Browser-based workflow using synthetic destinations and records.
- Agent network conforming to the contest's pinned [open agentic web specification](https://github.com/cognizant-ai-labs/agentic-web).
- Explicit consent scopes, denied-by-default forwarding, revocation and an inspectable audit trail.
- No actual personal, medical or financial information, real referrals, or autonomous external actions.

## Acceptance criteria
- [ ] Entrant contributes and reviews the original design.
- [ ] Verify specification version at the start of the submission period.
- [ ] Implement and validate interoperable in-browser agent network and required disclosures.
- [ ] Test scope denial, revocation, malformed messages and replay handling.
- [ ] Publish a publicly usable working demo and screenshots.
- [ ] Entrant records an English demo under two minutes and submits official materials.

Status: proposal only. No agent conformance, deployment, registration or submission claimed. AI-assisted planning.
